# Streamlit Projects

Deploying ML Models Using Streamlit

## Project Overview

This repository contains several beginner-friendly Streamlit apps demonstrating:

- simple UI creation
- stock market analysis
- machine learning model training
- model deployment with a web interface

## Files

- [intro.py](intro.py) — simple introduction to Streamlit widgets
- [intro.md](intro.md) — documentation for the intro app
- [stock.py](stock.py) — stock price analyzer
- [stock.md](stock.md) — documentation for the stock app
- [car_price.py](car_price.py) — model training script
- [car_price.md](car_price.md) — documentation for the training script
- [car_price_deploymet.py](car_price_deploymet.py) — deployed car price prediction app
- [car_price_deploymet.md](car_price_deploymet.md) — documentation for the deployed app

## Setup

Install dependencies using:

```bash
pip install -r requirements.txt
```

Run any app with:

```bash
streamlit run <filename>.py
```

Example:

```bash
streamlit run stock.py
```
