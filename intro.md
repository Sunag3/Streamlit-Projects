# Intro App Documentation

## File

- `intro.py`

## Purpose

This is a simple Streamlit starter app to demonstrate basic UI components and user interaction in Streamlit.

## Features

- Title and header sections
- Checkbox for accepting terms and conditions
- Radio button for choosing a movie genre
- Number input fields for arithmetic
- Calculation button that adds two numbers
- Success/error-style feedback with `st.success()`

## Example Flow

1. The app displays a welcome message.
2. User checks the agreement box.
3. A movie genre is selected from a radio list.
4. User enters two numbers.
5. The app adds them and shows the result after pressing the button.

## Main Components Used

- `st.title()`
- `st.header()`
- `st.subheader()`
- `st.write()`
- `st.checkbox()`
- `st.radio()`
- `st.number_input()`
- `st.button()`
- `st.success()`

## Notes

This file is intended as a beginner example and helps understand how Streamlit widgets can be combined to build interactive apps.
